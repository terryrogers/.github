# Support

## Questions & Usage Help

Use the repository's question issue form for installation, configuration, usage, & troubleshooting questions. Search existing issues first & include only public-safe information.

## Bug Reports

Use the repository bug-report form for a reproducible defect. Include public-safe logs, expected behavior, actual behavior, environment details, & minimal reproduction steps.

## Feature Requests

Use the feature-request form to describe the problem, intended outcome, alternatives, & expected users.

## Security Reports

Do not publish vulnerability details in an issue, discussion, or pull request. Follow `SECURITY.md`.

## Conduct Reports

Follow the confidential route in `CODE_OF_CONDUCT.md`.

Public support does not guarantee a response time unless the target repository explicitly states one.
